# 手机详情页长公式排版

2026-11-18，`codex/ui-lab-polish`，基线 `531c26c`。

- 320×640 复现 PLL Na 的 21 步排成三行，「识别与公式」底部进入底栏约 15px。同尺寸 PLL Ga 的入口已在底栏上方，这次继续作为回归用例。
- 三阶详情在手机上最多用两行高度显示步骤。更长时可在步骤区纵向滚动。播放、单步和拖动进度会让当前步骤在区内可见，回到开头时复位。播放器画布与控制条尺寸沿用原值。
- 公式卡片按现有括号分组换行。放不下的括号组在完整的转法之间换行，支持无空格连写、宽转、全角括号和重复后缀。保留原显示文本、执行公式、步数和存储数据。详情的接线断言按 D40 更新。
- 本地截图位于忽略目录 `ui-review.local/long-formulas/`，含 PLL Ga 与 Na 在 320 和 390 下的改前、改后及公式卡片。
