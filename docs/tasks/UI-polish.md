# UI-polish 公式列表与详情页视觉打磨

## 背景与目标

2026-11-11，用户希望前端更好看，授权先打磨公式列表和详情页。
基线 main `a3b7d39`，实现分支 `codex/ui-polish`。当前为本地待审版本，未合并、未发布。

沿用用户此前选定的圆角卡片、暖灰背景和橙色品牌色，统一字重、间距、信息层级。

## 改动

- `SetPage.tsx`：返回公式库入口、标题与方法名称；五个学习状态在一行完整展示，分类改为原生选择框；显示结果数量；空筛选结果可一键恢复。继续沿用原来的筛选条件和内存恢复。
- `CaseCard.tsx`：图解 76→64px，卡片内边距 10→16px，公式 13.12→14px、颜色加深；原来仅靠颜色表示的学习状态改成文字标签；加轻量箭头。此组件也用于首页搜索结果。
- `CasePage.tsx`：收藏移到标题旁，单图限定 64×64px；长名称使用较小字号，保留全文；弱化学习状态框线和次要操作。LSE 双图的后续修复见下方 UI-polish-fix。
- `styles.css`：统一卡片/公式行的留白；列表去掉逐项入场和卡片位移动画；详情公式去掉双重强调描边；识别说明和正文分出层级。保留已有圆角 token、深浅色、触控反馈与焦点框。
- 主题切换实测发现 `.route` 的入场动画节点可能沿用旧的继承文字颜色，显式绑定 `color: var(--text)`，使标题与正文主题色同步。

## 分类轻浮层动效（2026-11-11）

- 用户选择方案 1。只在 CategoryPicker 上增加 200ms 淡入、8px 上移和 0.985→1 的轻微缩放；收起 150ms，遮罩淡入 160ms，选项按压/勾选反馈 100ms，与收起并行，不额外等待。
- 退场重影修正：`category-out` 前 70% 保持 opacity=1，只做位移和缩放；最后 30%（约 45ms）再淡出到 0，既避免中段背景透出，也避免结尾硬切。遮罩仍独立在 150ms 内淡出。进入动画、所有时长、reduced-motion 规则与组件交互逻辑不变。
- 使用 CSS 动画和组件关闭阶段，无新增依赖。退出结束前保留模态状态和滚动锁，结束后恢复入口焦点；重复 Esc 忽略，动画事件缺失时 200ms 兜底，组件卸载时清理监听与计时器。减少动态效果直接关闭且取消变形和过渡。
- 保留原有所有断言；新增正常动效、展开时 Esc、重复关闭、退出期间仍为 modal、选择后四个结果、焦点和滚动恢复，以及减少动态效果检查。两种手机视口均通过。
- 静止几何保持不变：320 的弹窗 x=12 / 296×327，390 的 x=12 / 366×327；入口覆盖、40px 关闭按钮、浅深色和无横滚检查继续通过。
