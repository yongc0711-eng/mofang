# UI-polish 公式列表与详情页视觉打磨

## 背景与目标

2026-11-11，用户希望前端更好看，授权先打磨公式列表和详情页。
基线 main `a3b7d39`，实现分支 `codex/ui-polish`；已合并 main `cb29b7c`，GitHub Actions 部署成功。

沿用用户此前选定的圆角卡片、暖灰背景和橙色品牌色，统一字重、间距、信息层级。

## 改动

- `SetPage.tsx`：返回公式库入口、标题与方法名称；五个学习状态在一行完整展示，分类改为原生选择框；显示结果数量；空筛选结果可一键恢复。继续沿用原来的筛选条件和内存恢复。
- `CaseCard.tsx`：图解 76→64px，卡片内边距 10→16px，公式 13.12→14px、颜色加深；原来仅靠颜色表示的学习状态改成文字标签；加轻量箭头。此组件也用于首页搜索结果。
- `CasePage.tsx`：收藏移到标题旁，单图限定 64×64px；长名称使用较小字号，保留全文；弱化学习状态框线和次要操作。LSE 双图的后续修复见下方 UI-polish-fix。
- `styles.css`：统一卡片/公式行的留白；列表去掉逐项入场和卡片位移动画；详情公式去掉双重强调描边；识别说明和正文分出层级。保留已有圆角 token、深浅色、触控反馈与焦点框。
- 主题切换实测发现 `.route` 的入场动画节点可能沿用旧的继承文字颜色，显式绑定 `color: var(--text)`，使标题与正文主题色同步。

## 验证

- `npm test`：3748 项通过；原有测试文件、断言未修改。
- `npm run check:data`：393 项通过。
- `npm run build`：通过。
- `npm run test:visual -- --workers=2`：14 项通过（原有 10 项 + 新增 4 项）。新增检查覆盖五个筛选按钮的可见/触控范围、分类和状态组合、收藏、返回恢复、空结果重置、320/390 浅深色的溢出和标题色、PLL Ga / OLL 4 / CMLL / LSE 的提示条与底栏避让。
- 播放器画面高度仍为 320×640 下 164px、390×844 下 190px；播放、步骤、配色和 3D 实现未改。
- 另行检查了 1280×900 的列表/详情浅深色，以及 320×640 的长名称 `lse-ulur-24`；未发现横向溢出，长名称提示条在底栏上方。
- 对比截图位于被忽略的 `ui-review.local/`，before 为当时线上版本，after 为本地构建。截图使用相同设备尺寸、主题和默认用户数据。

## 范围与限制

这轮仅打磨列表、详情和共用的搜索结果卡片；首页五组入口、试转、练习、「我的」及导航外观保留。
没有改路由、用户数据结构、公式、ID、SET_RULES、求解和打乱逻辑；没有引入依赖、图片或字体。

尚需用户在真实手机上看整体观感和分类面板触控。本轮未专门验收系统放大字号。
