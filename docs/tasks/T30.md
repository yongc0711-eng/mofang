# T30 所有 2D 图解和练习页 setup 说明跟随六色底

## 背景

T28 只把 `bottomColor` 接到了公式页（`CasePage`）；`CaseDiagram` 已经有 `bottom` 属性，但公式卡片（`CaseCard`，组页和搜索页在用）、首页封面、练习页的图解都没传，所以底色改了以后只有公式页变，其余地方还是标准配色。练习页 setup 的朝向说明（T25）也是写死的“白色…绿色…”。

## 目标

1. 公式卡片、首页封面、练习页的图解都跟着底色。
2. 练习页的朝向说明跟着底色动态生成，白底时与 T25 原文逐字相同。
3. 只传参和加两个推导函数，不改 T28 的配色算法，不改 T29 的 `recognitionFor`，不改公式数据。
4. 只做 2D，3D 不扩到公式页以外。

## 允许改

`CaseCard.tsx`、`HomePage.tsx`、`PracticePage.tsx`、`devicePrefs.ts`（只加 `frontColor`）、新增 `src/lib/setupText.ts` 和它的测试、本文件；必要时 `CaseDiagram.tsx` 只补 top 接线。

## 改动

### 图解接线（只传参）

- `CaseCard`：`useDevicePrefs()` 取 `bottomColor`，传给里面的 `CaseDiagram`。组页（`SetPage`）和搜索页（`SearchPage`）走 `CaseCard`，自动生效。
- `HomePage`：同样取 `bottomColor`，传给每组的封面图解，包括 LSE 封面用的 `top` 视图。
- `PracticePage`：`Session` 里取 `useDevicePrefs()`，`CaseDiagram` 加 `bottom={prefs.bottomColor}`。
- `CasePage` 没动（T28 已做）。

**`CaseDiagram.tsx` 没有改。** 任务里说“若 `TopView` 没接 `bottom`，只在 `CaseDiagram` 里补 top 视图的接线”，实际上不需要：`TopView`、`IsoView`、`LseView` 都是纯粹按传入的 `colors` 数组画的，颜色在 `CaseDiagram` 里一次算好（`diagramColors(c, mask, bottom)`），所以三种视图（包括首页 LSE 封面用的 `top`）一接上 `bottom` 就都对了。top 视图的测试照要求加了（见下）。

### `frontColor`（`devicePrefs.ts`，只加这一个导出）

```ts
const F_STICKER = STICKERS.find((s) => s.face === 'F')!.id;
export const frontColor = (bottom) => FACE_COLOR[displayFace(F_STICKER, bottom)];
```

同 `topColor` 一样由 `displayFace` 推，没有另写表。结果：白、黄、红、橙 → 绿，绿 → 黄，蓝 → 白。`topColor` 没有重写。

### `setupText(bottom)`（`src/lib/setupText.ts`）

```
${b}色中心朝上、${f}色中心朝前起手；做完把魔方绕前后轴原地转 180°：${t}顶朝上、${b}底朝下，${f}色仍在前（不是前倾 90°）。
```

`b` 是底色，`f = frontColor(b)`，`t = topColor(b)`，中文名复用 T29 的 `COLOR_NAME_ZH`。

**与任务里的模板有一处不同：** 模板写的是 `${name(f)}仍在前`，会得到“绿仍在前”，而 T25 原文（也是任务要求逐字锁住的白底输出）是“绿**色**仍在前”。以锁定的原文为准，我写成 `${f}色仍在前`。

`PracticePage` 的固定那一行换成 `{setupText(prefs.bottomColor)}`；“摆出情形（setup）”标签、转动串、WCA 那行小字都没动。

### 白底文案原文

```
白色中心朝上、绿色中心朝前起手；做完把魔方绕前后轴原地转 180°：黄顶朝上、白底朝下，绿色仍在前（不是前倾 90°）。
```

六种底色的输出：

| 底色 | 输出 |
| --- | --- |
| 白 | 白色中心朝上、绿色中心朝前起手；做完…：黄顶朝上、白底朝下，绿色仍在前… |
| 黄 | 黄色中心朝上、绿色中心朝前起手；做完…：白顶朝上、黄底朝下，绿色仍在前… |
| 红 | 红色中心朝上、绿色中心朝前起手；做完…：橙顶朝上、红底朝下，绿色仍在前… |
| 橙 | 橙色中心朝上、绿色中心朝前起手；做完…：红顶朝上、橙底朝下，绿色仍在前… |
| 绿 | 绿色中心朝上、黄色中心朝前起手；做完…：蓝顶朝上、绿底朝下，黄色仍在前… |
| 蓝 | 蓝色中心朝上、白色中心朝前起手；做完…：绿顶朝上、蓝底朝下，白色仍在前… |

## 验收

- `npm test` 1308 项通过（原有 1290 项不变，新增 18 项），`npm run check:data` 393 项，`npm run build` 通过，`npx tsc --noEmit` 通过。没有改动、放宽或跳过任何旧测试。
- 新增测试在 `src/lib/setupText.test.ts`：
  - `frontColor` 六色映射；前色、底色、顶色三者两两不同。
  - `setupText`：白底逐字等于 T25 原文；六种底色各一条整句逐字断言；六句互不相同、每句里三个颜色名都在；去掉颜色字后句式完全一样（只有颜色名变）。
  - 接线：对 `CaseCard`、`HomePage`、`PracticePage` 的源码文本断言都有 `<CaseDiagram … bottom={prefs.bottomColor}` 和 `useDevicePrefs()`；练习页走 `setupText(prefs.bottomColor)`，不再有写死的“白色中心朝上”，摆出情形标签、转动串、WCA 说明原样保留。
  - 默认（不传 `bottom`）与白色渲染出的图解逐字相同，覆盖全部 254 个情形的各组自己的视图（卡片和练习页用的就是这些）；首页五个封面同样一致。
  - top 视图：黄底的图解等于白底按 z2（U↔D、R↔L）换色后的标记，位置和灰格都不变；iso、lse 视图同样；非白底时 LSE 封面的 top 视图确实变了。
- 组件本身不能在 node 里直接渲染（`useDevicePrefs` 用 `useSyncExternalStore`，服务端渲染要 `getServerSnapshot`），所以接线用源码文本断言，图解颜色用 `CaseDiagram` 直接渲染来测。

390 宽读数：`scrollWidth ≤ clientWidth`（无横向滚动）在首页、组页、搜索页、练习页、六种底色下全部成立；练习页 `practice-scramble` 区块右边缘 357px。
