# T50 首页第一屏的“底色可切换”提示

## 背景

用户不知道「我的」里能换六色底（T28）。

## 改动

- `src/pages/HomePage.tsx`：在 `<header className="home-head">` 里、公式计数下面加一行 `<Link to="/me" className="home-hint-link">想换魔方底色？到「我的」里切换 ›</Link>`。它在标题和计数之后、方法/课程卡之前。
- `src/styles.css`：`.home-hint`、`.home-hint-link`：`inline-flex`、`min-height: 32px`、强调色 `var(--accent)`、`max-width: 100%`、`overflow-wrap: anywhere`，没有固定宽度。
- 只是提示：首页没有切换控件；底色逻辑、默认值、六色映射、T28/T30/T48/T49、`docs/TASKS.md` 都没动。

## 测试

新增 `src/pages/homeBottomHint.test.ts`（5 项）：文案存在；是 `<Link to="/me">`，且只有一处；在标题、计数之后、`</header>` 和 `METHODS.map`（课程卡）之前；首页没有 `setDevicePrefs`/色块等切换控件，T30、T33 的接线还在；样式触控目标 ≥ 32px、只用变量、没有固定宽度。
