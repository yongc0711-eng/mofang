## 状态与随机规则

- PracticeScope.bottoms 默认 `[prefs.bottomColor]`；旧 scope 缺字段或为空时同样回到当前设备底色。初始化复制旧数组。
- 多选只进 `practice:scope` 的 uiState 内存，不调用 setDevicePrefs、不写用户备份或新的 localStorage 字段。已选色只剩一项时再点它不移除。
- 复用已有 `.swatches` / `.swatch` / `.swatch-on` 的换行、触控尺寸及深浅色变量；没有复制两份颜色表，也没有增加 CSS。
- Session 用 useState 复制 bottoms，练习期间固定范围。lastBottom 初始化只取恢复题 prepared.bottom，旧题未知底色不猜。
- pickBottom：空数组抛错；单色直接返回且不消耗随机数；多色先排除 last，再按随机索引选取。索引对负数、1、过大值、Infinity、NaN 等有边界保护；重复输入且没有其他颜色时返回唯一可用色。
- next 中抽色并更新 lastBottom，把 bottom 和 view/alg/reference 一起放入 Question；prepare effect 使用 requested.bottom，重试不换色，也不会随设备设置变化重染本题。
- 渲染优先级：`prepared?.bottom ?? question.bottom ?? prefs.bottomColor`。2D 两条分支和旧 setupText 均使用此 bottom；新题的 practiceInstructions 继续由同一 prepared 快照生成。
