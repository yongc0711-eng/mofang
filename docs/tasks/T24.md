## 行为

- ready / paused：主指针左键 pointerdown 捕获指针、设置 data-pressing=true；提示“松开开始”。pointerup 才开始/继续计时。
- running：pointerdown 立即停止，但不设置 heldPointer 或 pressing。这次 pointerup 因没有已准备的指针直接返回，不进入下一题。
- done：pointerdown 进入按下态，提示“松开下一题”；pointerup 只出下一题，回到 ready，不自动开始。
- 通过 setPointerCapture 接收面板外的松手；pointercancel / lostpointercapture 清除待松手指针及按下态，不调用 advance。只接受对应的 pointerId，排除非主指针、非左键、子链接/按钮。
- 松手前核对阶段没变、页面可见；阶段变化、页面 hidden、window blur、pagehide 均清除按下态，避免按住时切后台回来后误开始。它们只清瞬时交互状态，不暂停、冻结或改写 T21 计时。
- 去掉 pad 的 onClick 前进逻辑。Space 的既有 keydown/repeat/按钮链接排除逻辑未改，Enter 的现有行为保留。没有设置最短按住时长，快速点按松手也可以开始。

## 样式与滚动

.practice-pad 使用 touch-action:none、user-select:none（保留 -webkit-user-select:none）、新增 -webkit-touch-callout:none；onContextMenu preventDefault。仅对 pad 施加防长按/触摸默认动作限制，没有设置 body/html 的 overflow 或全局 touch-action。

按下态只把背景和边框切换到已有 --accent-soft / --accent；不加新颜色，不修改 padding、border-width、字号或高度，也不用会挤占高度的额外节点。提示沿用原位置，默认文案保持简短。data-pressing 仅属 UI，不存入会话。

重要区别：touch-action:none 意味着从 pad 内开始的触摸不用于原生滚动，这是按住计时所需的明确行为；页面整体仍可滚动，手机可从 pad 外的留白/顶部区域滑动。滚轮、滚动条、键盘不受该 CSS 限制。真机仍应确认外侧触摸滚动可用，不能把桌面键盘滚动当作手机滑动验收。
