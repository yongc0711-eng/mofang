## 修改

- pressing=true 和 running 共用一条反馈规则：背景 --accent-soft，边框/文字 --accent。提示等 .muted 子元素也随这两个状态使用 --accent。
- 数字在 pressing 和 running 都使用 --accent；按下规则的优先级高于 done 的绿色数字规则，避免 done 再次按住时遗留绿色。
- pad 去掉 background-color/border-color 的 0.25s 过渡；数字去掉 color 的 0.2s 过渡。两者仅保留 transform、opacity 的 0.12s 过渡，颜色立即切换。
- pad 增加 -webkit-tap-highlight-color: transparent。
- 仅在 pad 的 :focus:not(:focus-visible) 清除 outline；沿用全局 :focus-visible 的 2px --accent outline，不取消键盘可见焦点。
- 没有新增颜色、尺寸、缩放或位移；原有浅色/深色变量继续生效，done 未按住时保留完成态绿色。
