# T45 详情页的“学习状态”挪到标题下

## 背景

“学习状态”三段开关在 `.case-side` 底部（播放器下面），用户根本看不到。

## 改动

- `src/pages/CasePage.tsx`：把开关从 `.case-side` 挪进 `.case-head`，放在标题、分组、收藏按钮之后，整行一块，上面加“学习状态”小标题（`<h2 className="case-status-title">`）。`.case-head` 本来就在播放器和正文之前。
- `src/styles.css`：
  - `.case-head` 加 `flex-wrap: wrap`；新增 `.case-status`（`flex: 0 0 100%`、`min-width: 0`）。
  - `.status-seg`：加边框，按钮 `min-height: 44px`、字号 1rem；滑块用 `--accent-soft` 加 1.5px `--accent` 描边，选中文字 `--accent`、加粗。全部是 CSS 变量，浅色深色各自读自己的值。
- 没有改：三段的顺序、值（`none` / `learning` / `mastered`）、`setStatus`、localStorage 结构、筛选、统计、练习优先；没有第四态；T42 键盘、T44 动画、3D、数据、`docs/TASKS.md` 都没碰。

## 测试

新增 `src/pages/caseStatus.test.ts`（10 项）：

- 开关在 `.case-head` 里，在标题、收藏之后，只出现一次，不再在 `.case-side`；有“学习状态”小标题；
- 仍是三段，顺序和值不变，点击是 `setStatus(c.id, s)`；
- `STATUS_LABEL` 正是 未学 / 学习中 / 已掌握；
- 点击等于 `setStatus`：状态立刻变并写入 `mofang.user.v1`，结构仍是 `{version, cases}`；重新加载读回；只改这一个情形，其他情形、收藏不受影响；
- 练习页的筛选项和 `statusOf` 筛选没动；练习优先级学习中 > 未学 > 已掌握；
- 样式：整行宽、可换行、触控目标 ≥ 32px、选中用 `--accent`/`--accent-soft`、不写死颜色、没有固定宽度。

CasePage 不能在 node 里渲染（`useSyncExternalStore` 没有服务端快照），所以位置用源码文本断言，行为用真实的 `userStore`。
