# 我的收藏

2026-11-18，`codex/ui-lab-polish`，基线 `7f49c57`。

- 在「我的」点收藏数量进入列表。可切二阶和三阶，收藏按公式组展示，复用现有图解、主公式和学习状态。取消收藏后返回时，立即反映变动并保留所选阶数。只有二阶收藏时从「我的」默认进入二阶，其余默认进入三阶。
- 「练习收藏」打开当前阶数的收藏练习范围，使用现有开始练习按钮、配色和出题流程。另一阶的范围与未结束的练习会话保留。从详情返回时，直达范围不会覆盖之后的手动选择。
- 收藏继续使用原有本地数据和备份格式。决策见 D36。
