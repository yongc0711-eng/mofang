## 特征表

特征由现有引擎推出：对每条情形取 `caseState`（`algs[0]` 的逆作用于已还原状态），读 U 层四面各 3 块侧面贴纸的颜色。临时脚本跑完已删除，没有提交。

用语：

- **车灯**：一面上两个角的该面贴纸同色，中间棱不同色
- **色条**：一面三块同色
- **同色对**：角的一个面贴纸与该面中间的棱同色
- **后面**：车灯或色条所在的面，人站在它的对面看，左右前后都按这个视角。没有车灯和色条的情形不需要定后面

U 层转动（AUF）会把整行贴纸原样搬到另一个面，所以“车灯、色条、同色对”这类面内特征不受 AUF 影响。表里只用这类特征，以及它们之间的颜色关系，不依赖和中心块的对应。

| 情形 | 车灯面数 | 色条面数 | 同色对数 | 区分特征 |
| --- | --- | --- | --- | --- |
| Ua | 3 | 1 | 0 | 色条在后；左面的棱=前面的灯色，前面的棱=右面的灯色，右面的棱=左面的灯色 |
| Ub | 3 | 1 | 0 | 色条在后；左面的棱=右面的灯色，前面的棱=左面的灯色，右面的棱=前面的灯色 |
| H | 4 | 0 | 0 | 对面的两条棱互换 |
| Z | 4 | 0 | 0 | 相邻的两条棱互换 |
| Aa | 1 | 0 | 2 | 左前角的左面、前面各一对；车灯色第三块在右面的棱 |
| Ab | 1 | 0 | 2 | 右前角的前面、右面各一对；车灯色第三块在左面的棱 |
| T | 1 | 0 | 2 | 左后角的左面、右后角的右面各一对；车灯色第三块在前面的棱 |
| Ra | 1 | 0 | 1 | 左后角的左面一对；车灯色第三块在右面的棱 |
| Rb | 1 | 0 | 1 | 右后角的右面一对；车灯色第三块在左面的棱 |
| Ga | 1 | 0 | 1 | 左前角的左面一对；车灯色第三块在前面的棱 |
| Gb | 1 | 0 | 1 | 右前角的前面一对；车灯色第三块在右面的棱 |
| Gc | 1 | 0 | 1 | 右前角的右面一对；车灯色第三块在前面的棱 |
| Gd | 1 | 0 | 1 | 左前角的前面一对；车灯色第三块在左面的棱 |
| F | 0 | 1 | 0 | 色条在后；其余三面没有任何同色对 |
| Ja | 0 | 1 | 3 | 色条在后；同色对在左后角的左面、左前角的前面、右前角的右面 |
| Jb | 0 | 1 | 3 | 色条在后；同色对在左前角的左面、右前角的前面、右后角的右面 |
| V | 0 | 0 | 2 | 两对共用同一个角 |
| Y | 0 | 0 | 2 | 两对在对角的两个角上 |
| Na | 0 | 0 | 4 | 每面都在右边两块（从外面看） |
| Nb | 0 | 0 | 4 | 每面都在左边两块（从外面看） |
| E | 0 | 0 | 0 | 没有车灯、没有色条，也没有同色对 |

这 21 行的完整特征行互不相同。脚本里加了断言，重复就报错，实际没有报错。

## 坑

- `console.log` 在 vitest 里没有输出，临时脚本要写文件再读。
- 一开始只比较“几面有车灯、几面有色条”，区分不了 14 条。要加上同色对的位置和车灯色第三块的位置才分得开。
