# T69 长按选中收敛

## 问题

Android Chrome 长按标题、卡片、说明等界面文字时，会弹出“复制 / 分享 / 全选 / 网页搜索”的原生选择菜单；练习页已有 `user-select: none`，其他区域没有。

## 目标

- 界面文字默认不可长按选中：`body` 加 `user-select: none`、`-webkit-user-select: none`、`-webkit-touch-callout: none`。
- 公式和输入框保留可选中复制：`code`、`input`、`textarea`、`[contenteditable="true"]` 恢复 `user-select: text`。
- 不改复制按钮、路由、公式内容或任何交互逻辑。

## 非目标

- 不拦截链接/图片的原生“打开方式”菜单；如果后续仍出现，再单独加 `contextmenu` 处理。
- 不改变练习页已有的长按禁用。

## 验收

- 长按首页标题、方法卡、说明文字，不再出现文字选择菜单。
- 长按公式 `code.alg` 仍可选中、复制。
- 输入框仍可正常选择、编辑。
- 320/390 布局不变。

## 实现

- `src/styles.css`：`body` 关闭选中；`input, textarea, code, [contenteditable="true"]` 打开选中。
- `src/pages/longPressSelection.test.ts`：2 条样式契约测试。
- 门禁：`npm test` 3748/56、`npm run check:data` 393、`npm run build` 通过。
