## 2. 三个方向

三个方向都不改已有的颜色值，不加字体和图片，也不改五组入口的内容和顺序。

### A. 目录式（推荐）

- **气质：** 像一本书的目录。没有容器，页面只有一层背景，秩序完全靠字号、字重、灰度和间距。
- **色板：** 现有 token。全页只用 `--bg`；轨道改用 `--border`；彩色只留一处强调文字和绿色进度。
- **字体层级：** 28/600 → 17/600 → 13/600 → 13/400。
- **间距和圆角：** 行高 72（矮屏）或 78（高屏）；组间距 16 或 32；常态没有圆角和边框，按下时才出现 8px 圆角的底色。
- **布局变化：** 卡片变成行。图解 48px；第一行是名字+说明，第二行是已掌握；进度线放在文字列底部，同时起到分隔行的作用，不需要另加分割线。
- **代价：** 首页和其他页（仍是卡片）风格暂时不一致，要等后续页面跟进；可点击的感觉变弱，要靠箭头和按下反馈补；图解成为页面上唯一的彩色块，比现在更突出。

### B. 安静卡片

- **气质：** 保留现在的结构，只做减法，最稳妥。
- **色板：** 现有 token。卡片用 `--surface`，去掉边框和阴影，只靠底色差。
- **字体层级：** 同 A。
- **间距和圆角：** 行高约 70，卡片间距 8，统一 12px 圆角。
- **布局变化：** 卡片还在，内容压缩成两行。
- **代价：** 和其他页最接近，改动最小；但五个盒子还在，“留白”的提升有限。估算 320×640 下要压到约 70px 才放得下，比 A 紧。深色下卡片与背景的对比度只有约 1.1，分界比较模糊。

### C. 分组面板

- **气质：** 像系统设置，安静、熟悉。
- **色板：** 现有 token。每个方法一块 `--surface` 面板，内部用 `--border` 细线分行。
- **字体层级：** 同 A，但组名降到 16/600。
- **间距和圆角：** 行高约 64，面板 12px 圆角，组间距 20。
- **布局变化：** 五个小盒子合并成两块面板，图解 40px。
- **代价：** 三者中最省高度（估算）；但多了分割线，图解最小，容易看起来像“设置页”，缺少这个站自己的性格；宽屏下多列的面板也不好排。

### 对比

| | A 目录式 | B 安静卡片 | C 分组面板 |
|---|---|---|---|
| 贴合“克制、留白” | 最贴合 | 一般 | 较好 |
| 320×640 放下五组 | 已验证，余 21px | 估算刚好 | 估算余量最大 |
| 和其他页的一致性 | 暂时不一致 | 最好 | 中等 |
| 后续推广到其他页 | 要重新考虑列表页 | 最容易 | 中等 |

### 推荐 A

只有 A 真正符合“不靠装饰”的定义：B 和 C 仍然靠容器建立秩序。魔方图解本身已经是强烈的视觉锚点，不需要盒子再框一次。而且 A 预计只改 CSS，不改 `HomePage.tsx`，风险最小。

**验证：** 在页面上临时注入样式试过 A（没有写入文件，刷新后消失），只验证了 320×640 浅色和 390×844 深色：

- 320×640：LSE 底部在 547，底栏顶部在 568，五组都在首屏；无横向滚动。
- 390×844：LSE 底部在 623，下方余 149px；无横向滚动。
- 模拟了不同进度下的进度线。真实的已掌握数据和第 4 节的按下反馈还没验证。

## 4C. 首页逐块改法（方向 C，当前版本）

只改 `src/styles.css`，`HomePage.tsx` 没动。

- **Header、底色提示、更新提示、底部留白：** 同第 4 节。
- **组标题：** 13px / 600 / `--text`，说明 13px / `--muted`，放在面板外面。
- **面板：** 每个方法一块，`.set-list` 用 `--surface`、12px 圆角，没有边框和阴影。五个入口的内容和顺序不变。
- **行：** 高 68px（矮屏）或 72px（高屏）；内边距 12px；整行可点。
- **图解：** 44px。比方案估算的 40px 大，因为高度够用，而图解是这个站的主要信息。
- **分割线：** 只在同一面板的行之间，从文字列开始，不穿过图解。
- **文字：** 组名 16px / 600；说明和“已掌握 N / M” 13px / `--muted`。
- **进度条：** 高 3px，和“已掌握”排在同一行；第一列至少 5.75rem，所以各行的进度条左端对齐。轨道用 `--border`，填充用 `--ok`，动画 0.2s。
- **按下反馈：** 背景变成 `--surface-2`，被面板圆角裁切；桌面悬停相同，不做位移。
- **焦点框：** 面板会裁切外侧焦点框，所以 `.set-card:focus-visible` 把它画在内侧。
- **宽屏（≥ 800px）：** 两个方法各占一列，组标题和面板左对齐；不支持 `:has` 的浏览器退回单列。这条规则放在现有的桌面媒体查询里，因为 `playerPeek.test.ts` 要求那段是文件里第一个 `min-width: 800px`。

## 5. 共享 token 和底栏

**底栏（需要用户决定，默认不动）：** 问题 10、18 的根源在全站共享的底栏，严格按禁止项 19 不在第一版范围内。如果不动，安静的页面上会悬浮一个带模糊和两层阴影的胶囊，第一版的效果会打折。

## 6. 验收标准

**首页**

- 320×640（浅、深）和 390×844（浅、深）：五组入口都在底栏上方，没有更新提示时不用滚动。
- 五组入口的内容、顺序和路由不变；“共 N 条，已掌握 M 条”、底色提示、每组的“已掌握 N / M”和进度都在。

**命令和交付**

- `npm test`、`npm run check:data`、`npm run build` 全过，没有放宽或删除测试。
- 交付 before/after 截图：320 和 390、浅色和深色。

## 8. 本任务的禁止项（用户定，22 条）

1. 不要玻璃拟态、大面积模糊。
2. 不要渐变、霓虹、发光、光斑。
3. 不要重阴影、多层阴影、超大圆角。
4. 不要装饰插画、emoji 图标、背景图。
5. 不要多个强调色；最多一个品牌色 + 语义色。
6. 不要花哨字体或中文 webfont。
7. 不要大 hero 把五组入口推出首屏。
8. 不要横向滚动、轮播、嵌套滚动。
9. 不要卡片套卡片、过多分割线。
10. 不要隐藏、合并或重排五个组入口。
11. 不要滚动劫持、视差、超过 250ms 的动画、弹跳。
12. 不要 hover-only；触控目标不得小于 32px。
13. 不要首次进入弹窗、强制引导层。
14. 不新增 UI 库、动画库、字体、图片素材；要用先问用户。
15. 不做影响 canvas/3D 的全局 reset。
16. 不硬编码颜色，不绕过 styles.css 的 CSS 变量。
17. 不改路由、数据、公式、algs[0]、SET_RULES、求解/打乱。
18. 不为过测试放宽断言或删测试。
19. 第一版只改首页；共享 token 例外，但必须回归其他页。
20. 不直接合 main、不 push；先给分支和截图。
21. 不把“高级感”理解成黑金、奢华、性冷淡到不可读。
