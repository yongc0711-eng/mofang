# 二阶练习停表后的识别提示

2026-11-18，二阶 CLL、EG-1、EG-2 的停表结果新增可展开的「识别提示」。每次停表时默认收起，内容沿用详情页的底层、顶色和辨别提示，并从本题的持方与配色生成。

提示区支持触屏和键盘。展开、收起或点击提示正文时，练习保持在结果页。点「再练这题」仍回到原打乱，下一次停表重新收起提示。点计时区或在计时区按空格可以继续下一题。见 D33。

新增的手机浏览器用例覆盖 320×640 深色触屏和 390×844 浅色键盘，检查非白底的颜色文字、图解一致性、触控尺寸、无横滚、点击正文和重练流程。

构建、1,251 条数据校验、7,434 条单测和 38 条相关浏览器用例通过。浏览器用例在独立预览端口和产物目录运行，单测在浏览器测试结束后限制为两个工作进程复跑通过。
