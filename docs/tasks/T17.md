## 候选逐项决策

1. 不采用 .page max-width 1160：外宽从 1040 加 120，正文从 1008 加到 1128，首页与公式卡片仍为 3 列（四列公式卡片需要 1150 正文宽，首页需要 1190），每卡只从 329.33 拉到 369.33，没有增加列数；现有卡片截图无挤压，扩大只加长正文行。
2. 不采用 minmax(0,520px) minmax(0,1fr)：当前 494/494 合理；页面不扩宽时该候选会变成 520/468，把右侧识别及公式区缩小 26px，未见相应收益。
3. 不采用 .practice max-width 720：面板由 608 加到 688、内部由 574 加到 654，但当前实际面板已非 380，截图中打乱、图解、计时并未挤压，无须凭主观留白扩大点击区。
4. 唯一保留的修正：新增 @media (min-width:1200px)，.nav 的 padding-inline 改为 calc((100% - 1040px) / 2 + 16px)，匹配现有 .page 的正文边缘。1280/1440 无滚动条时由 24 改成 136/216；有滚动条时为 128.5/208.5，实测等于正文左边缘。
