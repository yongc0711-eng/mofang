# UI-2x2-polish：二阶查询界面修复

## 范围

用户要求修复二阶模块的 UI 问题，2026-11-15。基线 `8a6d41f`，在现有 `codex/ui-lab-polish` 分支追加提交；不合并、不 push。

## 修复

- 首页二阶 CLL / EG-1 / EG-2 不再把完整的长说明塞入固定高度卡片。显示简短适用条件，完整说明仍在原组页和卡片的 title 中。封面保持既有 320 下 96px、390 下 100px；折叠组卡把掌握数放在名称同行，展开组卡高 96px，说明、掌握数、进度均完整位于卡片内，不与翻卡页码重叠。CFOP / 桥式不变。
- EG 列表的顶/底视图由各 30×30 恢复为各 64×64，容器宽132px、gap4px；标题在图解右侧，公式独占下一行，避免压窄公式。CLL 单图仍64px；三阶 CaseCard 样式不变。
- 二阶图解改用带 figcaption 的 figure，显示“顶视 / 底视”，保留 SVG 的读屏名称与原朝向；首页缩略图不显示标签。
- 二阶详情收藏按钮移至返回行，标题按视口统一为20–24px，不再因名称长度突然改变；图解和标签占80px，收紧局部间距，六个邻换/对角换长名称不会把提示条挤入底栏。
- 二阶播放器在原有 stage 高度内预留40px速度区，canvas置于独立容器，速度按钮不再压住魔方。三阶仍使用原宿主结构，CubeScene / Timeline / 引擎与播放事件未改。
- AlgKeyboard 新增可选 size，默认三阶，原18个转法和所有编辑键不变；二阶只显示 R/L/U/D/F/B，保留三种后缀、退格、清空，说明同步改为二阶口径。手动输入不支持的切片/宽转仍由原校验拒绝，界面将其错误前缀转为中文，不放宽任何规则。

未修改数据、公式、ID、SET_RULES、cases2校验器、配色、路由、滚动恢复、练习、依赖或发布工作流。

## 二阶取景缩小（2026-11-15 追加）

用户认为二阶模型占画面过满，确认手机缩小约12%、桌面缩小约18%。在`82004a6`上追加修复，仅修改`CubeScene.resize()`中的二阶相机zoom：视口≤799px为0.88，≥800px为0.82。沿用现有ResizeObserver，窗口改变时重新取景；三阶相机仍使用原zoom=1，不改模型几何、旋转、引擎、数据或播放逻辑。

播放器、canvas、速度按钮、提示条、导航与2D图解的布局不变；320/390/1280、浅/深色六组浏览器实测与上一版几何逐项一致，单步与回到开头可用。只改取景，没有修改CSS或既有测试。

验证：`npm test`7150/70、`npm run check:data`1251/15、`npm run build`通过；`npm run test:visual -- --workers=2`74条通过，无skip。

截图：`ui-review.local/2x2-framing/before-{320,390,1280}-{light,dark}.png`与`after-{320,390,1280}-{light,dark}.png`；几何记录`geometry.json`。分支仍为`codex/ui-lab-polish`，不合并、不push。

## 复核与合并（2026-11-15，Auditor）

逐条看过两个提交（`82004a6`、`3bb8a7c`）的 `src` 与 CSS 改动，确认没有碰数据、`SET_RULES`、`cases2` 校验器、练习、路由与发布工作流；`CubeScene` 的 zoom 只在 `size === 2` 时写入，三阶仍是 1。

交付时的浏览器用例是 2 个视口 × 5 条：详情一条要连开 5 个情形（16.6s）、EG 长名称连开 4 个（13.2s），按 CI 2 vCPU 约 2.8 倍的放大会重新撞上 30s 上限（上一轮 `two-by-two.spec.ts` 就是这样红的）。因此在不删任何断言的前提下按「浅/深色 × 情形分组」重排成 26 条：首页 1 条不变，列表按 eg1/eg2 × 浅深色拆 4 条，EG 长名称按浅深色拆 2 条，详情按浅深色 × 两组 id 拆 4 条，键盘从详情里独立成浅深色 2 条，其余 13 条 × 2 个 project 共 26 条。单条最长 7.0s，整包 52.2s。

合并与门禁：fast-forward `8a6d41f..3490d7d`（`3490d7d` 为拆分提交），main 上 `npm test` 7150/70、`check:data` 1251/15、`build` 通过、`test:visual` 90 条（1.5m 本地实测 52.2s 为本 spec，全量 2.5m）全过，无 skip。
