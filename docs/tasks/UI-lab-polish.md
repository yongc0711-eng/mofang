# UI-lab-polish：试转页视觉整理

## 范围

用户要求优化试转页 UI，2026-11-15 继续完成。工作区 `D:/allwork/mofang-ui`，分支 `codex/ui-lab-polish`，基于 main `61b5d5b`。只调整试转页标记与局部样式；不合并、不 push。

## 现状问题与改法

- 原后缀、九键、更多和撤销/复原全部使用橙色背景/边框，视觉层级接近。改成中性九键，强调色只用于选中的后缀；末行整体转动键和更多面板中的切片键使用次一级灰度。
- 原后缀与“更多”挤在一组，撤销/复原和队列提示分成两行。后缀独立为具名分组，“更多转法”放在右侧；撤销/复原与队列状态收成一行。
- 魔方与键区分成两块轻边框区域，统一圆角与间距，不加装饰图片、渐变或 UI 阴影。390 下舞台由 220 增至 260px，320 保留 180px；宽屏仍左右排布。
- 标题、说明文字重新分级；原拖动/双击说明保留。加载/失败提示覆盖在舞台内，避免加载过程把底部控件推向导航栏。

## 保留的行为

15 个按钮和全部读屏名称保留；九个主键及九个更多键顺序、后缀持续锁定、16 步队列、撤销与复原、固定白顶绿前初始配色和设备材质偏好不变。原 Sandbox 模型、CubeScene、Timeline、CubePlayer、数据、SET_RULES、路由、依赖与发布工作流均未修改。
