# T29 OLL 识别文字跟随顶色

## 背景

T28 之后公式页可以选六种底面颜色，图解和 3D 的配色跟着换。但 OLL 的识别文字（`src/data/oll.ts` 里的 `recognition`）是按标准配色写的：“黄棱：…；黄角：…；侧面黄色：…”。选了红底以后，顶面贴纸画成橙色，文字还写“黄”，和图解对不上。

## 目标

1. 不改 `src/data/oll.ts` 的字符串，只在显示层替换。
2. 顶色用 T28 的映射推，不另写一张表：`topColor(bottom)` 由 `displayFace` 推出，白→黄、黄→白、红→橙、橙→红、绿→蓝、蓝→绿。
3. `CasePage` 渲染识别文字时，只对 OLL 把“黄”换成顶色的中文名；PLL、CMLL 等不动。白底必须逐字不变。
4. 纯函数加测试：六种底色 × 57 条 OLL，替换后不含“黄”（顶色是黄时除外）、非空、互异；白底与原文全等；“侧面黄色”也换。
5. 检查 OLL 页其他写死“黄”的图例或提示，有就跟随或改中性；遇到“黄绿”这类颜色对先停下说明。

## 允许改

`src/pages/CasePage.tsx`、`src/store/devicePrefs.ts`（只加 `topColor`）、新增 `src/lib/recognition.ts` 和 `src/lib/recognition.test.ts`、本文件。不改数据、`SET_RULES`、T28 的配色映射。

## 改动

### `topColor`（`devicePrefs.ts`）

```ts
const U_STICKER = STICKERS.find((s) => s.face === 'U')!.id;
export const topColor = (bottom) => FACE_COLOR[displayFace(U_STICKER, bottom)];
```

“顶色”就是原本属于 U 面的贴纸（标准配色下是黄色，OLL 里的“黄”指的就是它）在所选底色下显示成什么颜色。用 `displayFace` 推，没有另写表，也没有碰 `FACE_MAP` 和 `BOTTOM_ROTATION`。结果恰好是底色的对色。

### `recognitionFor(c, top)`（`src/lib/recognition.ts`，纯函数）

- `c.set !== 'oll'` 或没有识别文字：原样返回。
- OLL：`recognition.replaceAll('黄', COLOR_NAME_ZH[top])`。顶色是黄时得到的就是原文，逐字不变。
- 颜色的中文名放在 `recognition.ts` 里（`COLOR_NAME_ZH`），和「我的」页的叫法一致；「我的」页自己的那份没有动。
- 只依赖 `BottomColor` 这个类型，没有运行时依赖。

### `CasePage`

渲染识别文字时改成 `recognitionFor(c, topColor(prefs.bottomColor))`，“识别：”这个标签不变。

## 第 5 点的检查：没有需要停下说明的颜色对

- 57 条 OLL 识别文字里的“黄”一共只出现在三处：`黄棱：`、`；黄角：`、`侧面黄色：`，每条正好各一次。
- 这 57 条文字里没有出现任何其他颜色词（白、红、橙、绿、蓝），也就没有“黄绿”这类颜色对。测试把这一点锁住了：以后如果有人给 OLL 识别文字加了别的颜色词，测试会失败，提醒重新考虑“直接替换”是否还安全。
- OLL 页上其他写死“黄”的地方：公式页（`CasePage`、`CaseDiagram` 的渲染代码）里没有。源码里剩下的“黄”只在：
  - `CaseDiagram.tsx`、`devicePrefs.ts` 的注释；
  - `MePage.tsx` 里颜色选择的标签（它本来就是颜色名，不该换）；
  - `PracticePage.tsx` 的 setup 说明（T25 的文案，在练习页，不是 OLL 页，T28 的“后续风险”里已经记过）。
- `src/data/oll.ts` 文件头注释里也有“黄”（解释术语的注释，不会显示在页面上），没动。

所以没有需要“跟随或改中性”的图例或提示，也没有需要先停下来说明的情况。

## 坑

- 直接 `replaceAll('黄', …)` 只在“黄”只有一个意思时才安全。现在 OLL 的识别文字满足这一点，但这是数据现状，不是保证，所以用测试锁住“没有别的颜色词”。
- 顶色是“原本属于 U 面的贴纸现在显示成什么颜色”，不是“顶面中心的颜色”这么随手一写：它是用 `displayFace` 推出来的，换底色映射时自动跟着变，不会漏改。
- 不能只在显示层看“有没有黄”：白底时文字必须一字不差，所以顶色是黄时要原样返回，而不是“先换再换回来”。
