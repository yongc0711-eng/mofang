## 清洗规则

- JSON 解析失败、顶层不是普通对象、version 不等于 1、cases 不是普通对象：统一抛“不是有效的备份文件”，不覆盖当前数据。
- 单条情形不是普通对象：丢掉该条，继续处理其他条。
- times 非数组：丢掉字段；数组：仅保留有限且大于零的数字。
- status：仅保留 none / learning / mastered。
- favorite：仅保留布尔值。
- primaryAlg：仅保留字符串。
- customAlgs 非数组：丢掉字段；数组：仅保留字符串元素。
- 未知情形 ID 保留；顶层和单条情形的未知字段丢掉。
- 缺 times 或清洗后 times 为空的情形，timeStats 返回 null。

采用白名单构建新数据，在完成清洗后一次 commit；备份版本仍为 1，不改设备偏好，也不检查 ID 是否在当前公式数据中。
