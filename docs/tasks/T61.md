## 关闭、焦点与布局

右上角 ×、仅点遮罩本身、Esc 均可关闭。打开前入口显式取得焦点，打开后焦点进入关闭按钮；关闭 effect 清理后回原入口。通过 T50 提示程序点击入口时也返回实际入口，不落回提示文字。

Tab/Shift-Tab 在当前弹窗可用控件内循环，焦点意外落在外部时再次 Tab 也收回；tablist 采用 roving tabIndex，左右键循环，Home/End 定位两端。关闭/路由卸载移除监听并恢复 body 原 overflow，入口已离开 DOM 时不强行 focus。

弹窗打开期间锁 body 滚动；内容在弹窗内 overflow-y:auto，max-height=100dvh-32px。所有控件 >=44px；三列底色、两列/换行桥对延续原响应式规则。配色只用现有变量配合遮罩/阴影；浅深色共用结构。

portal 避免 route 动画 transform 成为 fixed 的包含块，overlay 高于底栏。弹窗不进入 main 文档流，不改变 T48 的详情高度预算；没有给详情增按钮或修改播放器 CSS。

实际交互：

1. 打开焦点在“关闭配色”，body overflow=hidden；Esc 后 dialog=0、overflow 恢复空串、焦点回 browse-colors。
2. 从 CFOP tab 按 ArrowRight，选中/焦点都为 Roux，出现交换按钮，只有一个 tabpanel。
3. 最后控件按 Tab 回关闭按钮；关闭按钮按 Shift-Tab 回最后的交换左右按钮。
4. 从 T50 提示打开后点遮罩，焦点返回 browse-colors；练习点 × 后回 practice-colors。
5. 浏览 CFOP 改绿底后练习初始化绿底；练习弹窗加蓝底，选中绿/蓝，但设备偏好仍仅绿底。
6. 回首页把浏览改红底，再回练习弹窗，池仍绿/蓝；刷新后设置池按原约定重置为浏览红底。两套状态没有持续联动。
