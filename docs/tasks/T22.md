## 问题与确认后的做法

原 scrambleFor 原样取 algs[0] 的逆，Aa/Ab 因此含首尾 x/x'。最初要求直接剥离首尾转体，但实测发现这会改变两条情形的贴纸状态。

用户随后明确授权：“允许等价改写面转：把 x/x' 包住的面转按旋转映射改写，保证打乱后逐贴纸等于 caseState(c)，同时输出无 x/y/z。”最终实现按此修订，不采用直接删词，不把状态比较放宽成归一化后相同。

1. 解析定义公式，定位连续的首部和尾部 x/y/z，涵盖正转、逆转、半转和组合。
2. 中间若还有转体，明确抛出带 case ID 的错误，绝不静默输出。全部 254 条当前数据均未触发；另有合成反例验证此分支。
3. 设首部朝向序列为 P，对中间每步 m 求执行顺序 P、m、P 的逆的精确贴纸置换。用现有引擎构建的 45 种单步面转/宽转/中层转置换查找等价动作。不复制引擎坐标或转动方向表，也不修改它。
4. 对等价动作序列取逆；随机 AUF 的公式组、四种候选及选择逻辑完全不变（OLL/PLL/CMLL 前置随机 U）。
5. 练习打乱旁增加既有 muted small 风格的 span：“白顶绿前起手；做完转黄顶绿前（前后不变，上下、左右对调），再对照图解/公式”。只加文案，不改布局规则。

## 映射规则与 Aa/Ab

按动作执行顺序，x m x' 的基本面映射为 R→R、L→L、U→F、D→B、F→D、B→U；动作的正逆与半转随对应面保留。y 的映射为 U→U、D→D、F→R、R→B、B→L、L→F；z 为 F→F、B→B、U→L、L→D、D→R、R→U。逆转使用逆映射，半转重复映射两次，多个首部转体按复合置换处理。宽转与中层转使用精确置换匹配，必要时会改变中层转的正逆，不用简单字母替换猜测。

| 情形 | 等价无转体定义公式 | 无 AUF 打乱 |
| --- | --- | --- |
| Aa | R' F R' B2 R F' R' B2 R2 | R2 B2 R F R' B2 R F' R |
| Ab | R2 B2 R F R' B2 R F' R | R' F R' B2 R F' R' B2 R2 |

不需要改坐标系：上述是同一坐标系内的共轭等价动作改写，等价性由全部 54 张贴纸的置换判定。引擎黄顶绿前的颜色及方向约定保持原样；用户白顶绿前的物理起手和做完后的翻面通过文字提示说明，不重标引擎坐标。

`x A x'` 不可直接当作 A。Aa/Ab 原公式和删词后的面转都把中心留在原位，caseState 的中心朝向归一化无法消掉两种不同的棱角置换。最终输出直接等于已由 caseState 定义的目标状态，输出端不再使用 finish/normalize。
