# 学习中按公式组开练

2026-11-18，`codex/ui-lab-polish`，基线 `f512392`。

- 在「我的 → 学习中」为每个公式组显示学习中数量和「练习本组」。依当前列表实时计数。
- 入口预选当前阶数、指定公式组和「学习中」，沿用练习设置、保存的配色和会话恢复流程。「练习学习中」仍可练当前阶数的所有学习中情形。
- 浏览器用例分别使用三阶 PLL 和二阶 CLL，验证同组的已掌握情形、其他组的学习中情形都不进入范围，另一阶的练习范围可切回。
