# T44 自绘公式键盘展开动效

## 范围

分支 `codex/t44-keyboard-motion`，直接基于 `main@7f7d7ea`。只改 CasePage.tsx、styles.css、caseInput.test.ts，另新增本文。没有修改键位、编辑逻辑、inputMode、scroll-margin、保存/校验、TASKS.md 或其他测试。

## 改动

- 保留 keyboardOpen 条件渲染、requestAnimationFrame 和取消帧清理。
- 下一帧读取 `window.matchMedia('(prefers-reduced-motion: reduce)').matches`：普通模式对现有 wrap 调用 `scrollIntoView({ block: 'nearest', behavior: 'smooth' })`；减少动效使用 `auto`。
- 不设置全局 scroll-behavior，不影响其他页面的滚动。
- 面板使用 `alg-keyboard-enter 170ms ease-out`：opacity 从 0 到 1，translateY 从 7px 到 0。动画作用于内层面板，scrollIntoView 仍定位外层 wrap。
- 只动画 transform / opacity，不动画 height、margin、padding，不分帧改变面板占位。条件挂载时最终布局一次就位，随后仅改变绘制；没有增加第二次撑高或折叠过程。
- 没有 pointer-events、disabled、延迟启用或动画完成回调；面板一挂载即可点选。关闭仍立即卸载，无退场和延迟状态。
- 减少动效媒体块明确设置 `.alg-keyboard { animation: none; }`，不只依赖已有的全局 0.01ms 动画降速规则。
- 原 wrap 的 `scroll-margin-bottom: calc(76px + env(safe-area-inset-bottom))` 完全未动。

## 测试

caseInput.test.ts 原 T42 测试及其四个断言逐字保留，新增四项：

1. 从实际页面源码提取滚动 effect，替换 matchMedia、rAF 和 scrollIntoView 后执行，验证普通模式下一帧 smooth，清理时取消帧。
2. 同一实际 effect 在 reduced-motion=true 时精确调用 auto。
3. 关闭状态不调度滚动；源码仍以 keyboardOpen 条件卸载，没有延迟退出。
4. 读取真实 CSS，验证 170ms ease-out、7px 位移及 opacity，关键帧不包含布局或交互屏蔽属性，减少动效禁用面板动画、没有全局 scroll-behavior，原滚动留白保持。

首次新增 CSS 断言因 Vitest 的 CSS 导入处理获得空串而失败，后改为 readFileSync 读取同一 CSS；所有动画断言保留，没有放宽预期。滚动两个分支不只是匹配关键词，而是执行实际 effect body。
