# T54 公式 tab 记住离开前的公式页（含组页）

## 背景

T51 只记“上次详情页”`lastCaseId`。在组页（如 `/set/cmll`）点进卡片但没选具体公式时，从“我的”再点“公式”会被旧的详情页顶掉，看起来像“又回到了上次的公式详情页”。

## 行为

- 离开公式区前，把当前路径写入内存 `lastFormulaPath`（`/`、`/set/…`、`/case/…`）。
- 在“我的 / 搜索 / 练习”点“公式”：优先回 `lastFormulaPath`；组页就回组页，详情页就回详情页，首页就回首页。
- `lastFormulaPath` 无效或没有时，退回 `lastCaseId` 拼出的详情页；再没有才回 `/`。
- 仍然只存内存，刷新后回首页；不写 localStorage、userStore 或备份。

## 改动

- `src/lib/nav.ts`：`formulaTabTarget(pathname, lastFormulaPath, lastCaseId)`，前两个参数都可空。
- `src/App.tsx`：`Nav` 里 `useEffect` 在公式区写 `setUi('lastFormulaPath', pathname)`；计算 `formulaTo` 时同时读 `lastFormulaPath` 和 `lastCaseId`。
- `src/pages/CasePage.tsx`：保留 `lastCaseId` 写入，作为回退。
- 测试：`src/lib/nav.test.ts` 增加“组页优先于旧详情 / 无效路径回退 / 首页也记住”等断言；`src/lib/scrollRestoration.test.ts` 的源码接线同步。
