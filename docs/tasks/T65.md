# T65 首页卡片比例与全站大圆角

## 背景

T64 把首页五张方法卡改成独立卡后，320/390 下卡片高度仍是 64px，宽度 288/358px，视觉上偏宽扁。用户 m05507 要求：

> 1把首页卡片上下做宽点好看点的比例 然后所有有框的地方给我用大r角好看点

## 目标

- 矮屏卡片从 64px 提高到 68px，高屏从 64px 提高到 78px，改善宽高比。
- 320×640 仍然保证五张卡全部在底栏上方；不横向滚动。
- 所有有边框的卡片、面板、输入、按钮、弹窗统一使用更大的圆角；胶囊（999px）、圆点（50%）、进度条（2px）保持原样。

## 允许改

- `src/styles.css`
- `src/pages/homeStyle.test.ts`
- `docs/tasks/T65.md`、`docs/TASKS.md`、`docs/decisions.md`

## 验收

- `npm test` 全过；`npm run check:data` 393 通过；`npm run build` 通过。
- CDP 设备视口 320×640：五卡各 68px，LSE 底 ≤ 568px（底栏顶），`scrollWidth === innerWidth`。
- 390×844：五卡各 78px，LSE 底 ≤ 772px。
- 首页卡片、公式卡片、播放器、练习面板、配色弹窗、输入框、按钮、键盘、统计块都显示更大的圆角。

## 非目标

- 不改公式数据、路由、配色逻辑、练习 setup/求解/计时、T58/T60/T61/T62/T63/T64 的行为。
- 不删除 999px 胶囊、50% 圆点、2px 进度条这些有意的形状。
- 不引入依赖或图片。

## 进展

- 2026-11-09：新增圆角 token：`--radius-card: 20px`、`--radius-panel: 24px`、`--radius-control: 14px`、`--radius-small: 10px`；把卡片、播放器、练习面板、弹窗、输入、按钮、公式行、分段控件、统计块、键盘、更新提示等改为 token 或 16px 大圆角。
- 卡片：矮屏 68px、高屏（`min-height: 720px`）78px；高屏图解 44px、内边距 10px 12px。
- 为保住 320 五卡：标题下计数间距 10→6、标题下边距 2→0、header 下边距 12→8、方法组间距 16→12、方法标题下边距 6→4。320 header 由 110.5 降到 104.5，LSE 底 554.5，底栏顶 568，净空 13.5px。
- 390：卡片 78px，LSE 底 656.5，底栏顶 772，净空 115.5px；1440 宽屏两列各 78px。
- 测试：`homeStyle.test.ts` 的卡片高度断言 64→68，并新增高屏 78px 断言；圆角断言从 `12px` 改为 `var(--radius-card)`。其余断言保留。
