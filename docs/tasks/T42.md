## 行为

- 默认收起；输入框获得焦点（含点击）或点击“公式键盘”按钮时展开，可用“收起公式键盘”关闭。
- 六列对应 R / L / U / D / F / B，三行分别为 X / X' / X2，共 18 个完整 token 按钮。均经 parseAlg 测试识别为单步。
- 追加到草稿末尾，清除首尾空白后补一个分隔空格；连续点击不会新建双空格。不重排或解析重写手输内容，内部空格、括号等保持原样。
- 退格删除末尾一个 Unicode 字符，并清掉末尾空白；例如 `R U' F2` → `R U' F`，再退格 → `R U'`。无空格的手输串也只退一个字符，不会整串删除。
- 清空删除全部草稿；空草稿禁用退格/清空，转法键始终可用。
- 采用 setDraft(current => editAlgDraft(current, edit))，连续操作基于最新草稿，避免过期值覆盖。
- 输入框保留原 onChange、自动大小写等属性，没有设置 readonly、disabled 或 inputmode=none，不禁止系统键盘。手动输入与点选可以混用。
- 所有键盘及展开按钮 type=button，位于原保存提交逻辑之外；不会触发保存。编辑时清提示的行为与原手输一致。
- 不新增 M/E/S、整体转体或宽转按钮；这些原有手输能力不变。此键盘是输入辅助，不绕过各组的原有合法性限制。
