# T42 “添加我的公式”的点选键盘（修正版）

## 最终交互

按用户修正，键盘改为“基础转法 + 独立后缀”，不再把 R/R'/R2 分别排成三键。

- 三行基础转法：`R L U D F B`；`r l u d f b`；`M E S x y z`。
- 底行：独立 `'`、`2`、退格、清空，共 22 个按钮。
- 先点转法，再点后缀：`r` → `'` → `M` → `2` → `S` → `'` 得到 `r' M2 S'`。
- 后缀作用于最后一个转法；重复点击同一后缀取消，切换则替换。例如 R → R' → R2 → R，不产生 R22 / R''。
- 空草稿禁用后缀、退格及清空；没有可修改的末尾转法时，后缀不插入孤立字符，也不修改括号组重复次数。手输 Rw 也可加后缀。
- 输入框获得焦点或“公式键盘”按钮展开，可收起。手动输入、系统键盘保留；没有 readonly 或 inputmode=none。
- 转法追加到末尾，自动补单个分隔空格，保留手输内容内部格式。退格删除末尾一个 Unicode 字符；清空删除全部草稿。点选不按中间光标位置插入。

## 范围与保存边界

- 分支 `codex/t42-alg-keyboard` 基于用户指定 `6bafb48`，T40 收尾后开始；不混入 T40。
- CasePage 只接入键盘与编辑状态。保存函数已经与指定基线逐文本比对，`saveFunctionUnchanged: true`。
- 不改 userStore、公式数据、校验器、TASKS.md。键盘所有按钮都是 type=button，不提交保存。各组原有限制仍由原校验器处理，例如 LSE 不会因出现 R 按钮就放宽允许转法。
- 模块：AlgKeyboard.tsx、algKeyboard.ts、CasePage.tsx、styles.css，及两份键盘测试。
