# 停表后再练这题

2026-11-18，二阶和三阶的停表结果在「查看详情」旁新增「再练这题」。点击后回到零秒的待开始状态，沿用原题的打乱、配色、图解和参考公式。再次停表时记录新的用时，并让本轮计数加一。点计时区或按空格仍可从停表结果进入下一题。

重练只重置计时状态，已准备好的题目随会话保存。重练按钮消失后，焦点回到计时区，页面回到顶部，便于重新看到打乱。停表时允许纵向滑动查看结果。设计见 D32。

新增浏览器用例覆盖二阶触屏、三阶键盘、零秒待开始、原题快照和图解、刷新恢复、两条用时分别保存，以及触屏和空格进入下一题。
