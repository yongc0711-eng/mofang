## 实现

- 标题右侧放「三阶 / 二阶」分段按钮，默认三阶。选中状态提供 `aria-pressed`，按钮提示“切换后复原魔方”，触控高度 32px。与标题同行，只比旧标题行高 1px，保住 320px 首屏预算。
- 二阶显示 R/U/F、L/D/B 两行六键，不显示更多转法；保留无 / 撇 / 2 后缀、撤销、复原和 16 步队列。模型层也拒绝整体转体、宽转和切片，避免仅靠 UI 隐藏非法动作。
- `Sandbox` 新增默认值为 3 的 `size` 参数，二阶状态、转动与复原均走现有 `cube2` 的 24 贴纸引擎。转动时长、锁定后缀、队列与撤销逻辑沿用原实现；三阶的九键与更多九键保持原样。
- `CubeSandbox` 根据阶数给内部组件不同 key，让模型、异步加载、WebGL 场景和动画同时重建。切换清空后缀、历史及队列，并恢复默认视角；清理时取消 RAF、销毁旧场景，已过期的加载不创建场景。重复选择当前阶数不复原。
- 两阶均沿用试转固定白顶绿前与设备表面材质，不接浏览/练习配色，不写用户数据或设备偏好。阶数只在当前页面挂载期间保存，离开再进入默认三阶。
- 截图发现二阶在独立舞台中底角贴边，给 `CubeScene` 新增默认值为 1 的取景倍率，只在试转二阶传 1.15；既有 camera.zoom、公式详情二阶取景及三阶均保持原值。新增上下 6px 边带无彩色面贴边的画面检查。舞台高度仍是 320 下 180px、390 下 260px、桌面 380px。

未修改魔方引擎、公式数据、ID、SET_RULES / SET_RULES_2、播放时间线、练习、用户数据、路由、依赖或发布流程。所有新样式沿用 CSS 变量。
