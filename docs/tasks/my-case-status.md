# 我的已掌握与学习中入口

2026-11-18，`codex/ui-lab-polish`，基线 `56a56f9`。

- 「我的」三张统计卡均可点击。「已掌握」与「学习中」复用收藏列表的结构，支持切换二阶与三阶，按公式组浏览。只有二阶匹配时从「我的」默认进入二阶。
- 详情里修改学习状态后，返回列表仍停在原阶数，列表和统计数量立即更新。沿用原收藏、学习状态和备份数据。
- 从列表进入练习时预选对应阶数与学习状态。复用收藏的直达和会话恢复流程。收藏地址继续兼容，见 D37。
