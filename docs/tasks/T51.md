# T51 底部“公式”tab 回到上次详情页

## 背景

T49 已按 case 记住选中公式，但 `App.tsx` 里“公式”NavLink 固定 `to="/"`：从“我的 / 搜索 / 练习”点它只回首页，看不到刚才的详情页。

## 行为

- 在公式区（`/`、`/set/…`、`/case/…`）点“公式”：回 `/`（点当前 tab 仍能回首页）。
- 在别的 tab 点“公式”：有记录就回 `/case/<上次的 id>`，没有就回 `/`。
- 记录只存在内存（`uiState`），刷新页面后没有记录，回首页；不写 localStorage，不进 userStore，不进备份。

## 改动

- 新增 `src/lib/nav.ts`：`isFormulaPath(pathname)`、`formulaTabTarget(pathname, lastCaseId)`（纯函数）。
- `src/App.tsx`：`Nav` 用 `isFormulaPath` 判断高亮，用 `formulaTabTarget(pathname, getUi('lastCaseId', null))` 算“公式”的 `to`。路由表没动。
- `src/pages/CasePage.tsx`：case 有效时 `setUi('lastCaseId', c.id)`（`useEffect`，依赖 `c?.id`）。
- 没动：T49 的 `readCaseSelection` / `rememberCaseSelection`、`src/data`、`SET_RULES`、`docs/TASKS.md`、`userStore`。

## 测试

新增 `src/lib/nav.test.ts`（9 项）：公式区三种路径（有没有记录都回 `/`）；`/me`、`/search`、`/practice` + `cmll-o-1` → `/case/cmll-o-1`；同样路径 + `null`/`undefined`/空串 → `/`；`/setx`、`/cases`、`/case` 不算公式区；254 个真实 id 都能拼出路径；接线（CasePage 只 `setUi`、不碰 localStorage，App 只调 `formulaTabTarget`，路由表不变，T49 的接线不变）；`uiState` 内存读写。
