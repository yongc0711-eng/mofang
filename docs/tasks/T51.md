# T51 底部“公式”tab 回到上次公式页

## 背景

T49 已按 case 记住选中公式，但 `App.tsx` 里“公式”NavLink 固定 `to="/"`：从“我的 / 搜索 / 练习”点它只回首页，看不到刚才的详情页。

T51 最初只记“上次详情页”；T54 修订为记“离开前停留的公式页”，首页、组页（`/set/…`）、详情页（`/case/…`）都算。否则在组页没选具体公式时，点“我的”再点“公式”会被旧详情页顶掉。

## 行为

- 在公式区（`/`、`/set/…`、`/case/…`）点“公式”：回 `/`（点当前 tab 仍能回首页）。
- 在别的 tab 点“公式”：回到离开前停留的公式页（首页/组页/详情页）。
- 没有公式页记录时，退回上次详情页；再没有就回 `/`。
- 记录只存在内存（`uiState`），刷新页面后没有记录，回首页；不写 localStorage，不进 userStore，不进备份。

## 改动

- 新增 `src/lib/nav.ts`：`isFormulaPath(pathname)`、`formulaTabTarget(pathname, lastFormulaPath, lastCaseId)`（纯函数）。
- `src/App.tsx`：`Nav` 用 `isFormulaPath` 判断高亮；`useEffect` 在公式区把当前 `pathname` 写入 `uiState` 的 `lastFormulaPath`；用 `formulaTabTarget` 算“公式”的 `to`。路由表没动。
- `src/pages/CasePage.tsx`：case 有效时继续 `setUi('lastCaseId', c.id)`，作为没有 `lastFormulaPath` 时的回退。
- 没动：T49 的 `readCaseSelection` / `rememberCaseSelection`、`src/data`、`SET_RULES`、`docs/TASKS.md`、`userStore`。

## 测试

`src/lib/nav.test.ts`（10 项）：公式区三种路径都回 `/`；别的 tab 回上次公式页（组页优先于旧详情）；无效/空记录退回上次详情；两者都没有回 `/`；`/setx`、`/cases`、`/case` 不算公式区；254 个真实 id 能拼路径；接线（App 写 `lastFormulaPath`、读两个记录，CasePage 只 `setUi`、不碰 localStorage，路由表不变）；`uiState` 内存读写。
