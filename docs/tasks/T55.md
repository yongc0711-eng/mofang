# T55 “组页 → 我的 → 公式”要按两次返回才回首页

## 复现

首页 → CMLL 组页 `/set/cmll` → 我的 `/me` → 公式。之后第一次系统返回/侧滑仍停在 `/set/cmll`，第二次才回首页。

## 原因

`/set/…` 不是详情也不是 tab 页，点“我的”用 push；回来时“公式”用 replace 把 `/me` 换成 `/set/cmll`，历史变成 `[首页, 组页, 组页]`，重复了一条。

## 改法

- **去搜索/练习/我的的链接带 state**（`tabLinkState`，`src/lib/nav.ts`）：
  - 从首页/组页出去（push）：`{ fromFormula: 当前路径 }`；
  - 从别的 tab 出去（replace，上一条历史没变）：把已有的 `fromFormula` 带过去；
  - 从详情出去：不带（详情本来就被 replace 掉了）。
- **“公式”的 onClick**（`shouldPopToFormula`）：当前不在公式区，且 `state.fromFormula === lastFormulaPath`（要回的正是 push 出来的那个公式页）→ `preventDefault` + `navigate(-1)`，不 replace。其他情况（详情来的、记录对不上、刷新后没有记录）保持原来的 replace，T51/T53/T54 的行为不变。
- 判断抽成 `nav.ts` 的纯函数；`App.tsx` 只调用它们，`replace` 的表达式、`formulaTabTarget`、`lastFormulaPath` 记录、路由表都没动。T49 的选中记忆没碰。

## 历史栈对照

| 路径 | 之前 | 之后 |
| --- | --- | --- |
| 首页 → 组页 → 我的 → 公式 | `[首页, 组页, 组页]` | `[首页, 组页]`，返回一次回首页 |
| 首页 → 我的 → 公式 | `[首页, 首页]` | `[首页]` |
| 详情 → 我的 → 公式 | `[…, 组页, 详情]` | 不变（T53），返回回组页，不回我的 |
| 组页 → 我的 → 搜索 → 公式 | `[首页, 组页, 组页]` | `[首页, 组页]`（来源一路带着） |

## 测试

新增 `src/lib/navBack.test.ts`（19 项）：

- `tabLinkState`：首页/组页/详情/别的 tab/乱写的 state；
- `shouldPopToFormula`：该后退的三种、不该后退的（公式区内、没来源、对不上、没记录、来源不是公式页）；
- 用最小历史栈模型（push / replace / 后退）照 App 的规则走了 10 条路径：首页→组页→我的→公式→返回一次是首页且没有重复；首页→我的→公式；详情→我的→公式→返回是组页不是我的；组页→我的→搜索→公式；首页→我的→搜索→公式；详情→我的→搜索→公式；反复进出；刷新后没有记录；来源和记录对不上；公式区内点“公式”仍回首页；
- App 接线（源码文本）：`state={tabState}`、`onClick={onFormulaClick}`、`navigate(-1)`、T54 的记录和调用没动、路由表没动。

模型里的 push/replace/后退语义是我按 react-router 的行为写的，不是真实的 router；真实行为用下面的浏览器验证。

### 已在桌面浏览器里验证（390×844，每条先整页刷新清空内存状态）

- 首页 → CMLL 组页 → 我的 → 公式 → 返回**一次**：首页（历史长度没有因为回到组页而多出一条）。
- 首页 → 我的 → 公式 → 返回一次：直接离开本页回到更早的页面，说明没有重复的首页。
- 组页 → 详情（滚动 300）→ 我的 → 公式 → 返回：组页（滚动 700 恢复）；再返回：首页。
- 组页 → 我的 → 搜索 → 公式 → 返回：首页；首页 → 我的 → 练习：tab 之间切换历史多 0 条。

## 没有验证的

- **真机侧滑 / Android 返回键**（任务要求的验收之一，我在桌面没法做）：需要你在手机上走“首页 → CMLL → 我的 → 公式 → 侧滑/返回键”，看是不是一次回首页。
- `navigate(-1)` 依赖“上一条历史就是要回的公式页”。我们靠 `fromFormula` 和 `lastFormulaPath` 对上来保证；如果用户在 tab 页用浏览器的前进/后退手动绕过，两者对不上时会退回原来的 replace，不会出错，只是可能多一条重复。
- iOS Safari 自带的边缘侧滑动画与 `navigate(-1)` 的先后，没有真机验证。
