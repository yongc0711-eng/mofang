# T59 练习完成后的图解对齐主公式

2026-11-08；基线 main `043782e`；独立工作树 `D:\allwork\mofang-t59`；分支 `codex/t59-practice-diagram`。

## 现象与根因

OLL/PLL/CMLL 选择主公式后，详情按 viewCaseFor 的 canonical 起手渲染。练习的 c 已由 practiceViewFor 得到同源 view，但 prepared.state 是 sampleTarget 的本题实际目标，可含随机 AUF（OLL/CMLL 另可能有 Ua 变化）。原渲染只判断 prepared 是否存在，done 也使用此目标，导致显示的主公式与完成后图解朝向不一致；顶面及侧面条均可能错位。

## 修改：仅选择渲染输入

在 PracticePage 内提取可测试的 PracticeQuestionDiagram 渲染边界，Session 将已有 c、set、bottom、prepared、phase 原样传入：

- prepared 存在且 phase 不是 done：保持 state={prepared.state}，包括 ready/running/paused。
- done：CaseDiagram 仅传 c/view/bottom，不传 state，使用 canonical，与详情的同一主公式 view 一致。
- prepared 为 undefined 或 null：同样回退 canonical，不访问缺失 state。

没有修改 case/view 的生成、目标采样、sampleTarget、scrambleFor、prepareSetup、solveTarget、随机分布、setup 串、3D、计时/会话恢复或样式。不是把训练目标改成 canonical。原提示文案也未改；其中“图解显示本题实际终态”现在仅适用于训练期间，done 为主公式对照图。
