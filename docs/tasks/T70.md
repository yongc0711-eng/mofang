# T70 视觉冒烟

## 目标

用无头浏览器在 320×640、390×844 两个手机视口快速检查主要页面「有没有明显坏掉」：白屏、横向溢出、关键按钮被底栏盖住、弹窗超出屏幕、焦点没有回到入口。

只做布局断言，不做像素级截图对比。失败时保留截图和 trace，方便人工看。

## 覆盖

1. 首页：五张方法卡都在底栏上方，配色入口至少 44×44。
2. 公式详情：`oll-4` 主公式显示括号，播放器不超宽。
3. 练习设置：开始按钮可见可点，练习配色弹窗能开、能关，焦点回入口。
4. 首页配色弹窗：CFOP/Roux 两个 tab、关闭按钮、弹窗在视口内，切换 tab 正常。
5. 试转：魔方舞台、九键、撤销/复原都在底栏上方。

两个项目都跑一遍，共 10 条。

## 实现

- `playwright.config.ts`：`testDir: ./e2e`，两个 viewport project，`serviceWorkers: 'block'`，`reducedMotion: 'reduce'`，失败留截图/trace。
- `e2e/visual-smoke.spec.ts`：`scrollWidth <= clientWidth + 1`、`toBeInViewport`、元素底边不越过 `.nav` 顶边、弹窗 bounding box 在视口内、关闭后 `toBeFocused`。
- `webServer` 用 `vite preview` 起已构建的 `dist`，端口 4173。

## 运行

```bash
npm run build
npm run test:visual
```

首次需要浏览器：

```bash
npx playwright install chromium
```

## CI

`deploy.yml` 在 `npm run build` 后安装 Chromium 并跑 `npm run test:visual`；失败时上传 `test-results` 与 `playwright-report`，并且不会发布 Pages。

## 非目标

- 不做像素快照、不做跨浏览器矩阵（只 Chromium）。
- 不替代 T16 真机验收：真实 iOS Safari、Android Chrome、微信 X5 仍需人工。
- 不检查 3D 画面内容，只检查舞台高度、按钮和遮挡。

## 已知取舍

- 3D 在无头环境可能走软件渲染；测试只等 `.sandbox-stage` 出现，不断言 WebGL 像素。
- 中文/字体差异不影响布局断言；如果以后加像素快照，需要固定字体。
- 只覆盖五个主路径，新增页面要补到本文件。
