# T64：首页方法卡视觉与 A 方案定稿

日期：2026-11-09。基线 main `bb250dc`；分支 `codex/t64-home-cards`；工作树 `D:\allwork\mofang-t64`。

## 结论

用户从 A/B/C 三个方向中选定 **A 独立学习卡**，并要求把 C 的橙色圆形箭头并入 A。生产首页现在固定为 A + 圆形箭头；B/C、`?cards=`/`?tone=` 预览开关和雾蓝配色都已移除。

## 定稿实现

- 每张方法卡是独立 surface：`background: var(--surface)`、1px `var(--border)`、12px 圆角、64px 高、6px 卡间距；左侧 2px `var(--accent)` 侧标，图解 40px，进度填充 `var(--accent)`。
- 右侧箭头改为 24px 圆形：`var(--accent-soft)` 底、`var(--accent)` 色，保留 `aria-hidden`，不新增焦点停靠点。
- 方法标题只显示 CFOP / 桥式 Roux，不再显示两行箭头说明；这是 A/B/C 预览阶段用户已确认的选择。
- 删除 `src/lib/homeCards.ts`（`?cards` 严格解析）与 `HomePage` 的 `data-cards`/`data-card-tone`；删除 styles 里 B/C、mist、`[data-cards]` 的实验规则。
- 不改路由、公式数据、`SET_RULES`、配色、搜索、详情、练习、T58/T60/T61/T63；不新增图片或依赖。
